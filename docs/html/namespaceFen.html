Detailed Description

Converts between FEN strings and game positions.

Forsyth-Edwards Notation (FEN) is a one-line ASCII string representing a chess position.

See also
https://www.chessprogramming.org/Forsyth-Edwards_Notation

It is implemented here to expedite the testing process, as the format is much more informationally concise than a grid printout or the raw data.
