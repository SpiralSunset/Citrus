Detailed Description

The system responsible for finding good moves to play.

This is the "brain" of the program; the core of the decision-making process. It looks ahead at the different paths a game can take and determines the one with the highest chance of winning.

◆ find_best_move()

Move Searcher::find_best_move ( Position pos)

Finds the ideal move that can be made from a given position.

It is a depth-first negamax search. The larger the depth, the more informed the search will be. However, this will also exponentially increase the time it takes to arrive at an answer.

The following optimizations are in use:

  • Alpha-beta pruning
