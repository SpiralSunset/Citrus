Detailed Description

Represents the game state on a particular turn.

A chess position is an arrangement of pieces, whose turn it is, what castling is permitted, the target square for en passant (or lack thereof), the Halfmove Clock, and the number of black turns that have occurred since the game's beginning.

Essentially, it is the game at a specific moment.

void Position::unmake_move ( Move move)

Reverts the position to how it was before the last move.
