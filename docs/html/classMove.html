Detailed Description

Represents a movement of a chess piece.

Here, a piece movement is represented as a 16 bit word. Bits 15-9: where the piece is moving from Bits 8-3: where the piece is moving to Bits 3-0: special move flags

The special move flags indicate what type of move is being performed.
