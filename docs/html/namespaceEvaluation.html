Detailed Description

Utilities for determining the value of a position.

These are used to provide position scores for the Searcher. The score is measured in centipawns, or one-hundredth of a pawn.

Function Documentation

◆ evaluate()

int Evaluation::evaluate ( Position & pos)

Evaluates the value of a given position.

If a position favors the white side, the number will be more positive. Likewise, a position favoring black will be more negative.

The following are used to determine the output:

  • Material
  • Piece Square Tables
  • Tapered Eval
